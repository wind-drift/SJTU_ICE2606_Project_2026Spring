  \medskip
  \raggedright\footnotesize
  \begin{itemize}
    \item 总体上准确率随 SNR 提高而上升；由于验证集较小且 CNN 为单次测试，局部存在波动
    \item 低 SNR（$-10$, $-5$ dB）：CNN 数据增强带来优势
    \item 中高 SNR（$\ge 5$ dB）：GMM 时序建模 + CMVN 归一化表现更好
  \end{itemize}

\begin{frame}{总结、局限性与团队分工}
  \begin{columns}[T]
    \column{0.50\textwidth}
    \textbf{已完成工作}
    \begin{itemize}
      \item 基于短时能量端点检测的自动语音切分
      \item 完整 MFCC 特征提取（预加重 $\to$ 分帧 $\to$ FFT $\to$ Mel 滤波 $\to$ DCT）
      \item 传统方法：KNN 基线 + GMM 模型
      \item 深度方法：TinyKeywordCNN 训练与评估
      \item 混合噪声下 7 级 SNR 鲁棒性评估
    \end{itemize}

    \medskip
    \textbf{核心结论}
    \begin{enumerate}
      \item MFCC 特征对数字语音有良好区分度
      \item 动态特征、序列建模、CMVN 与 GMM 似然判决共同提升了传统方法性能
      \item 本验证集纯净语音和中高 SNR 下 GMM 更优；低 SNR 下 CNN 受噪声增强影响较稳
    \end{enumerate}

    \column{0.46\textwidth}
    \textbf{局限性}
    \begin{itemize}
      \item 验证集仅 20 样本，统计意义有限
      \item 单一混合噪声类型，未测试各噪声单独影响
      \item 未进行说话人交叉验证
      \item 深度学习未尝试残差、注意力等架构
    \end{itemize}
